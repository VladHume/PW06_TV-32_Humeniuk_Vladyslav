# Практична робота 6 · Варіант 4

Гуменюк Владислав Васильович, ТВ-32.

**Файли PDF тестування ресурси і підготовка релізу**

Предметна галузь: атомна електростанція з радіаційним моніторингом. Пости й радіаційні показники вигадані. Акселерометр телефону вимірює прискорення, а не радіацію.

Це послідовні версії спільного навчального застосунку. Властивість `practical=6` визначає доступні екрани й окремий applicationId `ua.kpi.radmonitor.pw6`. Функції попередніх робіт зберігаються. Код поділено на пакети `ui`, `viewmodel`, `data`, `domain` і `device`. Екрани розташовані у `ui/Screens.kt`, точка входу — `MainActivity.kt`.

## Запуск

Потрібні JDK 17, Android SDK Platform 35, Build Tools 36.0.0. Мінімальна версія Android: 8.0/API 26. Відкрийте корінь проєкту в Android Studio. Створіть локальний `local.properties` із `sdk.dir=/ваш/шлях/до/sdk` або використайте ANDROID_HOME.

```sh
./gradlew assembleDebug
./gradlew testDebugUnitTest lintDebug
./gradlew connectedDebugAndroidTest
```

Облікові записи навчального API: `operator@demo.ua` та `viewer@demo.ua`, пароль обох `Demo12345`. Реєстрація створює тимчасового спостерігача в пам’яті mock API. Room зберігає вимірювання між запусками. Для підключення локального HTTP-сервера див. [сценарій демонстрації](docs/DEMO.md).

## Матеріали

- `report/` — звіт Word за шаблоном викладача.
- `evidence/` — фактичні знімки застосунку з емулятора.
- `verification/` — результати перевірок і збірки.
- `docs/REQUIREMENTS.md` — відповідність вимог коду.
- `docs/AUDIT.md` — повторна перевірка всіх занять та обмеження.
- `docs/DEFENSE.md` — пояснення коду, сценарії демонстрації й можливі питання захисту.
- `docs/DEMO.md` — порядок демонстрації.
- `docs/RELEASE.md` — збірка, підпис і підготовка публікації.

APK розміщено у локальній папці `artifacts/` на робочому столі. У Git зберігаються вихідний код, звіт і докази перевірки. Ключі підпису не входять до репозиторію. РГР до цього проєкту не включено. Репозиторій публічний.

Додатково: `./gradlew -Pcoverage=true testDebugUnitTest coverageReport` генерує JaCoCo; `./gradlew -PwithFlavors=true assembleDemoDebug` демонструє product flavor. CI міститься як неактивований шаблон у `docs/ci/`.
