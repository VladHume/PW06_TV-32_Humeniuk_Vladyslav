# Сценарій демонстрації

1. Запустити APK. Увійти як operator@demo.ua з паролем Demo12345.
2. Оновити навчальний показник. Для 0,12 мкЗв/год і 8 год отримати 0,96 мкЗв. Спробувати від’ємне значення.
3. Додати демонстраційні пости. У журналі створити, відредагувати й видалити власний запис. Перезапустити застосунок і перевірити збережені записи.
4. Для PW03+ синхронізувати mock API. Спробувати HTTP 503 та некоректний JSON. Показати Snackbar. За потреби запустити `python3 server/demo_server.py`, ввести `http://10.0.2.2:8765/`, застосувати джерело, увійти повторно й виконати HTTP-синхронізацію.
5. Для PW04+ знайти Пост B, застосувати фільтр типу, змінити порядок. На мапі відкрити маркер. Надати або відхилити дозвіл GPS.
6. Для PW05+ показати акселерометр, історію, зміну кольору, масштабування й вибір точки. Увімкнути повідомлення та запланувати нагадування.
7. Для PW06 записати CSV і JSON, прочитати їх назад, експортувати. Додати фото/PDF. Створити PDF-звіт та експортувати через системний діалог. Переглянути CPU процесу, PSS та батарею.
8. Вийти й увійти як viewer@demo.ua з тим самим паролем. Кнопки зміни журналу приховані; ViewModel також перевіряє роль.

Знімки та тестові журнали в evidence/ і verification/ відображають фактичний запуск. Доступні екрани залежать від номера практичної, заданого властивістю practical.
