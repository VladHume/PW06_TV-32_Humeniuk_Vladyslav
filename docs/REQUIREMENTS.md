# Відповідність завданням

## Заняття 21: Анімація та інтерактивність

Плавний індикатор реагує на StateFlow, а натискання на графік відкриває значення точки. Темна та світла теми застосовуються до всіх екранів. 

Реалізація: `Gauge; DataChart`.

## Заняття 22: CSV і JSON

Експорт містить ідентифікатор, назву, тип, показники, координати та час. CSV підтримує лапки, коми й переноси в назві. Імпорт відхиляє дублікати ID, неправильні заголовки та невалідні показники. Фільтр 1, 24 або 168 годин обмежує дані у графіках після читання файла.

Реалізація: `domain/Domain.kt: Exchange`.

## Заняття 23: Фото і документи

Storage Access Framework дозволяє вибрати JPEG, PNG або PDF. Застосунок копіює документ у власне сховище, перевіряє MIME та обмежує розмір до 10 МБ. Фотографії відображаються через Coil. Додано DOCX, прив’язку вкладень до поста, перейменування, сортування та фільтрацію. PDF переглядається сторінками через PdfRenderer; DOCX має обмежений за розміром текстовий preview без повного відтворення верстки Word.

Реалізація: `FilesService.copyDocument; FilesScreen`.

## Заняття 24: PDF звіт

PdfDocument формує сторінки з поясненнями, таблицею та стовпчиковою діаграмою. Дані діляться на порції по 20 записів. Генерація виконується у Dispatchers.IO, а готовий файл можна експортувати через системний діалог. 

Реалізація: `FilesService.pdf`.

## Заняття 25: Модульні інтеграційні та UI тести

Тести охоплюють арифметику, граничні значення, CSV/JSON, ролі, HTTP-помилки та CRUD Room. Compose UI-тести перевіряють вхід, валідацію та розрахунок. Конфігурацію GitHub Actions підготовлено як шаблон для відтворення збірки й перевірок. Додаткові Android-тести перевіряють маршрут id, роль спостерігача, PDF/DOCX preview та дію підтвердження сповіщення. Окремий тест перевіряє міграцію Room. JaCoCo формує XML/HTML покриття локальними тестами; UI-покриття до цього відсотка не додано.

Реалізація: `app/src/test; app/src/androidTest`.

## Заняття 26: Моніторинг ресурсів

Кожні 2 с вимірюються CPU процесу як частка одного ядра, PSS пам’яті та заряд батареї. Показники не підміняються загальним CPU усієї системи. Налаштування теми зберігається у SharedPreferences. 

Реалізація: `ResourceSampler`.

## Заняття 27: Збірка та презентація

Підготовлено APK, конфігурацію release з R8, інструкцію підписування, метадані для Google Play та презентаційні матеріали. Реальне публікування у магазин потребує акаунта розробника й окремих дій власника. Налаштовано опційні flavors demo/full (-PwithFlavors=true), підготовлено графіку й опис поведінки даних для Play. Точні результати перевірки ОС, релізу та покриття наведено у verification/.

Реалізація: `Gradle; docs/RELEASE.md`.
