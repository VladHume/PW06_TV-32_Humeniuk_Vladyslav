# Поведінка даних навчального застосунку

АЕС Моніторинг Навчальний — демонстраційний застосунок, який не підключений до реальної АЕС. Радіаційні значення та координати постів вигадані.

Записи, документи, налаштування й навчальний токен зберігаються у приватному сховищі застосунку. Mock API обробляє навчальні облікові дані локально. За явного налаштування зовнішнього API дані входу надсилаються за вказаною адресою; потрібен HTTPS, крім локального тестового сервера емулятора.

Геолокація використовується на екрані мапи після системного дозволу. Вона не надсилається у mock API. Запити тайлів OpenStreetMap передають постачальнику тайлів IP-адресу та координати запитаних тайлів. Показники акселерометра/гіроскопа використовуються для локальної візуалізації й порогових подій.

Обрані через системний діалог фото й документи копіюються локально. Експорт файлів відбувається за дією користувача. Реклама, рекламні ідентифікатори, аналітика та покупки не інтегровані.

Дані можна видалити через системне очищення сховища застосунку або деінсталяцію. Експортовані копії потрібно видаляти окремо. Користувач може відкликати дозволи геолокації та сповіщень у налаштуваннях Android.
